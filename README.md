
# CaseWeaver – The AI Evidence Connection Engine

**An offline investigative evidence analysis and connection platform.**

## About the Project

CaseWeaver is a prototype application designed to help investigators organise and analyse digital evidence. It extracts useful information from evidence documents, identifies possible connections, highlights conflicting statements and presents findings in an organised format.

The application works offline and uses rule-based analysis.

## Key Features

- User login and registration
- Create and manage investigations
- Upload PDF and TXT evidence
- Evidence analysis and information extraction
- Identify connections between people, places, objects and events
- Investigative knowledge graph
- Investigation timeline
- Potential discrepancy identification
- Suggested follow-up questions
- Downloadable investigation reports

## Technology Stack

- Python
- Streamlit
- SQLite
- PyMuPDF
- Python-based analysis modules

## Running the Application

1. Install Python.
2. Clone or download this repository.
3. Install the required packages:

   `pip install -r requirements.txt`

4. Start the application:

   `python -m streamlit run CaseWeaver_app_v4_timeline_fixed.py`

## Important Note

CaseWeaver is a hackathon prototype intended for demonstration and educational purposes. Its findings are preliminary analytical suggestions, not verified conclusions. All evidence and outputs require human review. The CBI demo role, if enabled, is simulated and does not represent an official government account.
